# Minhag 📚💡

**Minhag** is an educational website designed to support students throughout their academic journey.  
It provides organized learning resources, interactive tools, and intelligent assistance to boost productivity and understanding.

---

## 💼 Key Features

- 📁 **Study Materials**: A well-structured archive of helpful PDFs and study guides.
- 🎓 **Educational Courses**: Simple and engaging courses in topics like AI, data structures, and programming.
- 🤖 **AI Chatbot**: A smart assistant that answers questions and helps with learning on demand.

---

## 🔧 Technologies Used

- HTML, CSS, JavaScript
- Node.js
- External libraries and frameworks (as needed)
- Bootstrap or SCSS
- Local file handling
